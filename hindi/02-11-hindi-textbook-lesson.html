बैंगनी जोजो · 紫色的乔乔（色彩与观察的故事）

课文一
一、印地语原文 (मूल पाठ)

बैंगनी जोजो

（मिलकर पढ़िए · 一起读吧）

जोजो एक सफ़ेद कुत्ता था।
वह एक पेड़ के नीचे सो रहा था।
"घर् र् र् र्! स्स्स्सस! घर् र् र् र्! स्स्स्सस!"

उसने देखा एक बादल को, आकाश में धीरे-धीरे चलते हुए।
"बादल, बादल, क्या तुमने दिए मुझे बैंगनी धब्बे?"
"नहीं," बादल बोला। "मैं तो सफ़ेद हूँ।"
बादल हट गया।
वह जग गया।
"भौं भौं! किसने दिए मुझे बैंगनी धब्बे?"

जोजो ने ऊपर सूरज को देखा।
"सूरज, सूरज, क्या तुमने मुझे दिए बैंगनी धब्बे?"
"नहीं," सूरज बोला। "मैं तो पीला हूँ।"

"कौए, कौए, क्या तुमने दिए मुझे बैंगनी धब्बे?"
"नहीं," कौआ बोला। "मैं तो काला हूँ।"

"गुब्बारे, गुब्बारे, क्या तुमने दिए मुझे बैंगनी धब्बे?"
"नहीं," गुब्बारा बोला। "मैं तो लाल हूँ।"

"घास, घास, क्या तुमने दिए मुझे बैंगनी धब्बे?"
"नहीं," घास बोली। "मैं तो हरी हूँ।"
बेचारा जोजो!
"ऊँ, ऊँ, ऊँ! किसने दिए मुझे बैंगनी धब्बे?"

टप! टप! टप!
"आहा! तो वह जामुन का पेड़ था!"

– समीरा ज़ीया कुरेशी（作者：萨米拉・吉娅・库雷希）

二、中文翻译 (अनुवाद)

紫色的乔乔

（一起读吧）

乔乔是一只白色的小狗。
它正睡在一棵树下。
"呼噜噜噜！嘶嘶嘶！呼噜噜噜！嘶嘶嘶！"

它看见天上有一朵云，正缓缓地飘过。
"云朵，云朵，是你给我弄上紫色斑点的吗？"
"不是我，"云朵说，"我可是白色的。"
云朵飘走了。
它醒来了。
"汪汪！是谁给我弄上紫色斑点的？"

乔乔抬头看见了太阳。
"太阳，太阳，是你给我弄上紫色斑点的吗？"
"不是我，"太阳说，"我可是黄色的。"

"乌鸦，乌鸦，是你给我弄上紫色斑点的吗？"
"不是我，"乌鸦说，"我可是黑色的。"

"气球，气球，是你给我弄上紫色斑点的吗？"
"不是我，"气球说，"我可是红色的。"

"青草，青草，是你给我弄上紫色斑点的吗？"
"不是我，"青草说，"我可是绿色的。"
可怜的乔乔！
"呜呜呜！是谁给我弄上紫色斑点的？"

嘀嗒！嘀嗒！嘀嗒！
"啊哈！原来那是棵胭脂果树！"

作者：萨米拉・吉娅・库雷希

四、重点语法讲解 (व्याकरण)
1. "谁"(कौन) 的作格形式 "किसने" 与及物动词完成时
疑问代词 कौन 加后置词 ने 变为 किसने（"是谁干的"）："किसने दिए मुझे बैंगनी धब्बे?"（谁给我弄上的紫色斑点？）。这是完成时及物句的"作格"标志，与"तुमने दिए"（你给弄的）、"उसने देखा"（他看见了）同源。
किसने दिए मुझे धब्बे? → 是谁给我弄上的斑点？
उसने एक बादल को देखा। → 它看见了一朵云。
2. 强调语气词 "तो" —— "我（可是）……的"
句中用"我 + तो + 颜色 + हूँ"来强调"我可根本不是那种颜色"："मैं तो सफ़ेद हूँ"（我可是白的）、"मैं तो पीला/काला/लाल/हरी हूँ"。语气词 तो 起着"撇清关系、强调本色"的作用，是这则对话反反复复的核心句式。
मैं तो सफ़ेद हूँ। → 我可是白色的。
मैं तो हरी हूँ। → 我可是绿色的。
3. 拟声词（商量音）：घरघर / भौं भौं / ऊँ ऊँ / टप टप
故事用一连串拟声词推动情节："घर् र् र् र्… स्स्स्सस"（小狗的呼噜声）、"भौं भौं"（汪汪）、"ऊँ, ऊँ, ऊँ"（嘤嘤的呜咽）、"टप! टप! टप!"（果子的滴答声）。每一个都让画面"有声"，是儿童故事最活泼的调味。
भौं भौं! किसने दिए धब्बे? → 汪汪！谁给我弄上的斑点？
टप! टप! टप! → 嘀嗒！嘀嗒！嘀嗒！（熟果坠落声）
4. 完成体复合动词 "हट गया / जग गया" 表状态变化
"动词词干 + गया"表示状态的突变或完结："बादल हट गया"（云飘走了）、"वह जग गया"（他一下子醒了）。配合前面学过的 भूल गए 等，it 是印地语描写"忽然发生变化"的万能结构。
बादल हट गया। → 云飘走了。
वह जग गया। → 它醒了过来。
5. 进行体"正……着"—— सो रहा था
故事开头的"वह ... सो रहा था"（它正睡着）用"动词的 रहना 进行体 + 过去"表示"过去某时正在进行的动作"。这个"रहा था"进行时在叙事中常用来铺陈场景、制造悬念。
वह एक पेड़ के नीचे सो रहा था। → 它正睡在一棵树下。
五、背景知识 (पृष्ठभूमि)

1. जामुन（胭脂果）——会"染色"的印度果子

जामुन（学名黑李/印度豆腐果，也叫 jamun、jambul）是南亚非常常见的紫色小果。它的果肉和汁液是深紫红色，吃了之后舌头、手指都会染成紫黑，很久都洗不掉。故事里乔乔睡在胭脂果树下，正是熟透坠落的果子把它的白毛染出了"紫色斑点"——一切都顺理成章。

2. 借"找斑点"复习颜色

乔乔一路问人：云白、太阳黄、乌鸦黑、气球红、青草绿……每个回答都在重申"每个事物都有自己的本色"。这正是第 8、9、10 课"色彩主题"的又一次复习与延伸，让孩子在逗趣的对话里记住各种颜色词及其读法。

3. 拟声词与"一起读"的朗读乐趣

课型为"मिलकर पढ़िए（一起读吧）"，特别适合分角色朗读：小狗乔乔、云朵、太阳、乌鸦、气球、青草各说各话，加上 घरघर、भौं भौं、टप टप 等响声，读起来有表演感。文后还让孩子设想乔乔遇到黑熊（भालू）、骆驼（ऊँट）时又会怎么对答，进一步活用句式。

4. 观察与探究的启蒙

故事真谛是"看见紫斑先不慌，问清来处自然明"——乔乔一路追问，最后用"啊哈！"揭晓答案。这种"发现问题 → 逐一排查 → 恍然大悟"的结构，正是科学探究精神最朴素的雏形，也呼应单元反复强调的观察自然。
