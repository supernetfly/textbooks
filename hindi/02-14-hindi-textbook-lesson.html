इकाई 3: हरी-भरी धरती（绿色的大地）· बीज · 种子（好奇与豁达的小诗）

课文一
一、印地语原文 (मूल पाठ)

बीज

（मिलकर पढ़िए · 一起读吧）

मुझे एक बीज मिला।
मैंने उसको गमले में डाला।
मैंने उसे पानी दिया और बहुत सारी धूप।

क्या यह पेड़ है?
क्या यह झाड़ी है?
क्या इसमें फूल होंगे?
क्या इसमें फल होंगे?
क्या यह लंबा ऊँचा होगा?
क्या यह छोटा ही रहेगा?

मुझे नहीं पता।
कोई फ़र्क नहीं पड़ता!

– दीपा बलसावर（作者：迪帕・巴尔萨瓦尔）

二、中文翻译 (अनुवाद)

种子

（一起读吧）

我捡到了一粒种子。
我把它放进花盆里。
我给它浇了水，还有满满一盆阳光。

它会是一棵树吗？
它会是一丛灌木吗？
它会开出花来吗？
它会结出果子来吗？
它会长得又高又大吗？
还是就保持小小的模样？

我不知道。
可那又有什么区别呢！

作者：迪帕・巴尔萨瓦尔

四、重点语法讲解 (व्याकरण)
1. 及物动词的过去式与"ने"结构
及物动词过去时，主语要加作格后置词 ने："मैंने उसको गमले में डाला"（我把它放进花盆）、"मैंने उसे पानी दिया"（我给它浇水）。注意"मुझे एक बीज मिला"则不然——मिलना（得到/遇见）是不及物动词，动词要跟"得到的东西"（बीज，阳性单数）变位，主语用与格 मुझे。
मैंने उसे पानी दिया। → 我给它浇了水。
मुझे एक बीज मिला। → 我捡到了一粒种子。
2. "क्या……?" 的一般疑问句
在陈述句前加 क्या 就变成"是……吗"的疑问句，且不需要改变语序或加"吗"字："क्या यह पेड़ है?"（它是一棵树吗？）、"क्या यह झाड़ी है?"（是一丛灌木吗？）。本诗连用六个 क्या 问句，把孩子的好奇一层层推向高潮。
क्या यह पेड़ है? → 它是一棵树吗？
क्या इसमें फूल होंगे? → 它会开出花来吗？
3. 现在时与将来时疑问的交替使用
对"现在它是什么"用现在时疑问（है）；对未来"会不会开花结果、长得怎样"用将来时疑问（होंगे / होगा / रहेगा）。从"现在的身份"到"未来的样子"，时间线随问题层层打开，正是儿童观察生命成长的视角。
क्या इसमें फल होंगे? → 它会结出果子来吗？
क्या यह लंबा ऊँचा होगा? → 它会长得又高又大吗？
4. "ही" 强调 + रहना 表"保持现状"
"छोटा ही रहेगा"中，ही 强调"恰好、偏偏"，रहना 表示"一直保持某个状态"："（它）就保持小小的样子吗？"这组结构常用于询问事物是否会一直维持现状。
क्या यह छोटा ही रहेगा? → 它是不是就一直是小小的呢？
5. "कोई फ़र्क नहीं पड़ता" — 无所谓的习惯表达
"फ़र्क पड़ना"（起区别、有关系），否定式"कोई फ़र्क नहीं पड़ता"= "一点区别都没有/无所谓"。全诗以这一句作结，把前面一连串好奇轻轻放下：无论长成树还是灌木，这粒种子都值得被珍视。正是这首诗最动人的"豁达"。
कोई फ़र्क नहीं पड़ता! → 那又有什么区别呢！
五、背景知识 (पृष्ठभूमि)

1. 种子与"绿色的大地"单元

本诗是第三单元"हरी-भरी धरती"的一环：从上一课认识池塘里的小生命，到这一课亲手种下一粒种子，单元在一步步建立孩子与自然的连接。诗中反复问"会长成树还是灌木"，正是生命教育最质朴的切入点。

2. "गमला" 花盆里的种植体验

在印度，家家户户阳台上常有 गमला（花盆），种着万寿菊、罗勒，甚至是香料。课后活动让小朋友在旧器物或花盆里种"काले चने（黑鹰嘴豆）"，几天后便能目睹嫩芽破土、长出小叶的奇迹，把诗中"生命成长"的想象变成亲手可触的观察。

3. पेड़ 与 झाड़ी 的植物学小知识

诗中问"它是树还是灌木？"。植物学上，पेड़（乔木）有单一的主干、长得高；झाड़ी（灌木）则从根部就分出多根枝条、较矮小。孩子区分二者，需要观察种子发芽后的茎与高度——这正是寓教于乐的"小小植物学家"入门。

4. "कोई फ़र्क नहीं पड़ता"的哲理

结尾的"无所谓"并不消极，而是把孩子的关注点从"它会长成什么"转移到"我好好浇水和晒它"这件事本身。它悄悄告诉孩子：生命的价值不在于最终长成什么形态，珍惜与陪伴的过程，才是最重要的。
